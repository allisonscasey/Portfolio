Overview

Rather than relying on static client-side formulas, we architected a layered, multi-service investment platform separating identity verification, quantitative math, AI tool orchestration, and relational persistence.

Authenticated users can evaluate individual mutual funds, compare deterministic growth curves against stochastic Monte Carlo outcomes, group saved calculations into custom portfolios, and export reports to Excel.

System Architecture

  • Angular & TypeScript Frontend: Built a single-page dashboard with Firebase route guards, shorthand input parsing, interactive projection charts, and a floating AI chat interface.
  • Spring Boot Backend Core: Developed REST endpoints handling Firebase token verification, live market data ingestion via Newton APIs, CAPM modeling, and Apache POI Excel exports.
  • FastMCP AI Tooling Layer: Integrated a Python tool-execution server enabling the OpenAI chat assistant to query mutual fund catalogs, run simulations, and generate portfolios via structured tool calls.
  • PostgreSQL on Google Cloud: Managed relational schemas via Flyway migrations to persist UID-scoped user accounts, portfolios, and JSONB 20-year time-series projections.

Modeling & Validation

Projection workflows fetch real-time beta and historical price deltas to compute CAPM annualized rates ($r = r_f + \beta(E[R] - r_f)$) and continuous compounding curves ($FV = P \cdot e^{rt}$). Alongside deterministic projections, our Monte Carlo engine samples randomized returns around historical means to surface percentile risk metrics across single funds and weighted portfolios.

End-to-End Verification: Validated all API endpoints, UID ownership rules, and database state transitions across Postman, pgAdmin, and Google Cloud runtime logs.
