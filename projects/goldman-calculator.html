Overview

As part of the Emerging Leaders in Engineering Program through Goldman Sachs, I was placed in a seven-student team, tasked with building a web application that estimates mutual fund returns using live market volatility (beta), US Treasury risk-free benchmarks, and Capital Asset Pricing Model (CAPM) continuous compounding.

I took on the role of front-end engineer, focusing on the user interfaces and how clients would be interacting with our platform. I utilized HTML, CSS, JavaScript, on an Angular framework. While my formal responsibility was on the front-end, our team would meet weekly to collaborate on the full-stack so that everyone could get experience on both front-end and back-end.

Beyond the core calculator requirements, we expanded into the challenge's advanced architectural tiers—implementing a cloud-hosted PostgreSQL database to persist user portfolios, multi-fund Monte Carlo risk comparisons, Excel reporting, and an OpenAI-powered portfolio advisor capable of generating optimized allocations based on risk tolerance and investment horizon.

The program cumulated in a presentation weekend in Dallas, TX where we did a technical presentation and live demonstration of our application to a panel of judges and Goldman engineers. We also got to tour the office, hear from employee speakers, and network with fellow students.

System Architecture

  • Angular & TypeScript Frontend: Built a single-page dashboard with Firebase route guards, shorthand input parsing, interactive projection charts, and a floating AI chat interface.
  • Spring Boot Backend Core: Developed REST endpoints handling Firebase token verification, live market data ingestion via Newton APIs, CAPM modeling, and Apache POI Excel exports.
  • FastMCP AI Tooling Layer: Integrated a Python tool-execution server enabling the OpenAI chat assistant to query mutual fund catalogs, run simulations, and generate portfolios via structured tool calls.
  • PostgreSQL on Google Cloud: Managed relational schemas via Flyway migrations to persist UID-scoped user accounts, portfolios, and JSONB 20-year time-series projections.

Modeling & Validation

Projection workflows fetch real-time beta and historical price deltas to compute CAPM annualized rates (r = rf + β(E[R] − rf)) and continuous compounding curves (FV = P · ert). Alongside deterministic projections, our Monte Carlo engine samples randomized returns around historical means to surface percentile risk metrics across single funds and weighted portfolios.

End-to-End Verification: Validated all API endpoints, UID ownership rules, and database state transitions across Postman, pgAdmin, and Google Cloud runtime logs.
