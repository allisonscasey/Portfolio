Goldman Sachs Mutual Fund Calculator

An educational investment analysis platform built by a seven-person engineering team under Goldman Sachs mentorship, combining quantitative return projections, Monte Carlo risk modeling, and an AI-powered portfolio advisor.

View GitHub Repository Watch on YouTube
Angular Spring Boot (Java 17) FastMCP (Python) PostgreSQL Firebase Auth Google Cloud

System Architecture

Rather than relying on static client-side formulas, we designed a layered, multi-service architecture separating user authentication, financial computation, AI tool orchestration, and relational persistence[cite: 4]:

Frontend (Angular & TypeScript)

Single-page dashboard with Firebase authentication guards, interactive deterministic vs. Monte Carlo projection views, portfolio management, and a persistent chat interface[cite: 4].

Backend Core (Spring Boot)

REST API layer handling token verification, CAPM financial modeling, external market data ingestion (Newton APIs), Excel workbook exports, and Spring AI orchestration[cite: 4].

AI Tooling Layer (FastMCP)

Python tool-execution server enabling the chat model to query mutual funds, run simulations, compare saved calculations, and generate tailored portfolios via structured tool calls[cite: 4].

Database (PostgreSQL on GCP)

Relational schema managed through Flyway migrations storing UID-scoped user profiles, mutual fund catalogs, portfolios, and JSONB time-series projections[cite: 4].

Quantitative Modeling & Key Features

  • CAPM Future Value Projections: Fetches live beta and historical return data to compute annualized rates ($r = r_f + \beta(E[R] - r_f)$) and generate 20-year exponential growth curves ($FV = P \cdot e^{rt}$)[cite: 4].
  • Monte Carlo Simulations: Runs randomized return sampling around historical means across both single mutual funds and weighted multi-asset portfolios to surface percentile outcomes and risk metrics[cite: 4].
  • End-to-End Portfolio Workflows: Supports saving calculations, grouping assets into custom portfolios, exporting reports to Excel via Apache POI, and validating API/DB consistency with Postman and pgAdmin[cite: 4].
